## 📚 Lab Scope & Focus Areas

- **🌿 Advanced Git Workflows**: Branching strategies, rebase vs merge, semantic commit tagging, and conflict resolution.
- **🐳 Containerization**: Writing clean multi-stage Dockerfiles, minimal base images (Alpine/Distroless), and microservice orchestration with Docker Compose.
- **⚙️ Continuous Integration**: GitHub Actions automated linting, test runners, and build artifact publishing.
- **🔒 Security & Linting**: Secret scanning, container vulnerability analysis (Trivy), and environment hardening.
